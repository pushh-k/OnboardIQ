# OnboardIQ

**OnboardIQ** is an AI-powered platform that helps open-source maintainers understand and improve the onboarding experience for first-time contributors.

Rather than only tracking repository activity, OnboardIQ analyzes onboarding metrics such as PR response time, review cycles, merge time, documentation quality, CI failures, and review sentiment to identify why new contributors may not return. It provides actionable insights and AI-driven recommendations to help maintainers reduce contributor churn and build healthier open-source communities.

## Features

* GitHub OAuth authentication
* Repository analytics dashboard
* First-time contributor tracking
* Onboarding health score
* AI-generated insights and recommendations
* Contributor retention risk analysis
* Interactive charts and metrics

## Tech Stack

* **Frontend:** Next.js, React, Tailwind CSS
* **Backend:** Node.js, Express
* **Database:** PostgreSQL (Prisma)
* **Authentication:** GitHub OAuth
* **AI:** OpenAI/Gemini
* **Visualization:** Recharts

## Problem Statement

While GitHub provides metrics like pull requests, issues, and review timelines, it doesn't explain **why first-time contributors stop contributing**. OnboardIQ bridges this gap by uncovering onboarding friction and helping maintainers create a more welcoming and engaging contribution experience.

## Future Scope
